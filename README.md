# DevizPRO V49

Aplicație web progresivă pentru devize, măsurători și administrarea lucrărilor. Această ramură conține versiunea V49 din arhiva furnizată, cu fișierele runtime organizate în structura folosită de aplicație.

## Deschidere
După publicarea GitHub Pages:
https://vladro11.github.io/devizpro/

## Instalare pe iPad / iPhone
1. Deschide adresa în Safari.
2. Apasă Partajare.
3. Alege „Adaugă la ecranul principal”.
4. Deschide DevizPRO din pictogramă.

Pe Android, deschide adresa în Chrome și alege „Install app” sau „Add to Home screen”.

## Funcționare offline și păstrarea datelor
- Deschide aplicația online cel puțin o dată, pentru ca fișierele principale să fie memorate local.
- Datele de lucru sunt stocate local în browserul/dispozitivul folosit. Nu există sincronizare automată între dispozitive.
- Exportă periodic backup din aplicație și păstrează-l într-un loc separat.
- Nu șterge datele site-ului sau stocarea browserului înainte de a face backup.

## Structura repository-ului
- Fișierele aplicației: rădăcina repository-ului.
- Stiluri și imagini: `assets/` și `Logo/`.
- Documentația tehnică și istoricul proiectului: `docs/`.
- Publicarea: GitHub Actions, din ramura `main`.
